### 📄 Paper 2 — Emotional Manipulation Attacks on LLMs: Benchmarking Alignment-Induced Compliance Failures
**`Under Review` → PLOS ONE**

```
✦ 7 attack types: anger, flattery, guilt, panic, parasocial attachment, moral outrage, peer pressure
✦ 5,584 adversarial prompts across 11 LLMs (3B–14B params)
✦ Emotional pressure flips >1 in 4 correct answers — True ASR up to 49.74%
✦ RLHF-induced compliance: bigger models are equally broken
```
`Python` `Hugging Face Transformers` `LLM Safety` `Adversarial NLP` `NumPy` `SciPy`

---

### 📄 Paper 3 — Hybrid Deep Learning for Morphological Classification of Planetary Nebulae
**`Under Review` → Astronomy and Computing**

```
✦ Two-stream network: EfficientNet + Haralick, Hu & Zernike morphological descriptors
✦ 94.24% CV accuracy (91.55% test) · AUC > 0.96 all classes · p < 10⁻⁴
✦ Physics-aware augmentation: 171 → 1,477 images without breaking plausibility
✦ CNN-only: 37.09% · Physics-only: 31.84% · Hybrid: 94.24% ✓
```
`Python` `PyTorch` `Keras` `EfficientNet` `Computer Vision` `CNNs`
